Architecture

From pixels to priority.

The dashboard is a thin local API over the existing inference pipeline. Nothing about the detector is reimplemented in the browser.

  3. 03

Severity engine

Not every defect is equal.

Severity is derived from the proportion of the frame each detection occupies. The bands are deliberately simple, explainable and identical across every workflow.

Good to know

Honest limits
  • Checkpoints and datasets are not bundled; the app states clearly when inference is unavailable.
  • Severity uses bounding-box area. Perspective and occlusion can affect it.
  • Video counts are frame-level detections; there is no cross-frame tracking.
  • Webcam capture requires browser camera permission and a localhost/HTTPS origin.
